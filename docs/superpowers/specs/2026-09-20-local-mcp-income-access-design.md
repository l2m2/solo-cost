# 本地 MCP 收入决策访问设计

## 目标

让用户在 ChatGPT Project Chat 中按需查询 `solo-cost` 的最新收入数据，用于客户、项目、回款和投入决策。现有本地 SQLCipher 数据库继续作为唯一权威数据源，不迁移到远端数据库。

首版只读。MCP 仅在桌面应用运行且数据库已解锁时提供数据；主密码、数据库文件、密钥材料和任意 SQL 均不对外暴露。

## 指标口径

所有金额以整数分为基础，并可附带格式化人民币。合同口径与实收口径必须分开返回，不得混用。

- 收入：合同不含税收入或实收不含税收入。
- 销售分成：潜在销售分成或已实现销售分成。
- 一般成本：项目发生的非人工成本。
- 到手：不含税收入减销售分成和一般成本。
- 人工收入：工时除以 8 后乘以工时记录保存的成员日成本快照。
- 剩余利润：到手减人工收入。

人工代表用户本人投入劳动获得的收益构成，不作为流向外部的现金支出。因此必须始终满足：

```text
到手 = 人工收入 + 剩余利润
```

潜在指标使用合同收入和潜在销售分成；已实现指标使用实收收入和已实现销售分成。响应必须明确标识所用口径。

## 架构

在 Tauri/Rust 进程中嵌入本地 MCP HTTP 服务。服务仅监听回环地址 `127.0.0.1`，由 OpenAI Secure MCP Tunnel 访问。应用不开放局域网或公网监听端口。

MCP 层调用 Rust 领域查询函数，不直接向模型暴露 SQL。收入计算集中在可复用的领域层，现有桌面界面与 MCP 共用相同口径，避免出现两套计算结果。

应用生命周期规则：

- 应用启动后可启动本地 MCP 监听。
- 数据库未解锁时，工具调用返回 `APP_LOCKED`。
- 应用锁定后，正在执行和后续的数据查询均不得继续访问数据库。
- 应用退出后服务随进程终止。
- MCP 服务不得保存、接收或记录主密码。

## 公司范围

默认查询当前选中的公司，并在每个响应中返回公司 ID 和名称。只有调用方明确传入 `scope: "all_companies"` 时才能跨公司汇总。跨公司结果必须保留公司维度，避免不同公司的财务数字被误合并。

## MCP 工具

### `get_income_overview`

默认决策入口。按公司、年份或日期范围返回合同收入、实收收入、潜在及已实现销售分成、一般成本、潜在及已收到手、人工收入和剩余利润。

### `rank_income_sources`

按客户或项目排行。支持收入、到手、人工收入、剩余利润和回款率排序。

### `get_project_decision_summary`

返回单个项目的合同与回款、销售分成、一般成本、工时、人工收入、剩余利润、回款进度和任务进度，并分别提供潜在与已实现口径。

### `get_income_trend`

按月或按年返回收入、到手、人工收入和剩余利润趋势。范围内没有数据的周期返回零值。

### `list_payments`

分页返回应收、实收、回款日期及未回款余额。

### `list_income_details`

按需下钻一般成本、销售分成和工时记录，用于解释汇总变化。支持类型、项目、成员、分类和日期筛选。

## 返回与限制

- 日期使用 `YYYY-MM-DD`，时间使用带时区的 ISO 8601。
- 每个响应包含 `generated_at`、公司范围和指标口径。
- 明细默认 50 条，最多 200 条，并提供稳定分页信息。
- 日期范围、排序字段和枚举值由服务端校验。
- 不返回软删除数据、数据库路径、密钥材料、内部 SQL 或未请求的备注全文。
- 普通问题优先返回汇总；只有明确要求解释或查看明细时才调用明细工具。

稳定错误码至少包括 `APP_LOCKED`、`NOT_FOUND`、`INVALID_ARGUMENT`、`INVALID_DATE_RANGE`、`RESULT_LIMIT_EXCEEDED` 和 `INTERNAL_ERROR`。错误不得泄露数据库路径、SQL 或密钥信息。

## 设置界面

应用设置页增加简洁的“ChatGPT 连接”区域，显示：

- 本地 MCP 地址。
- 数据库当前是否已解锁。
- Secure MCP Tunnel 的配置说明。

应用不保存或管理 OpenAI API Key；Tunnel 的凭据由 `tunnel-client` 自己的运行环境管理。

## 安全与日志

- MCP 服务只接受回环连接。
- 首版不提供写入、修改、删除、任意 SQL 或附件读取能力。
- 日志只记录工具名、查询范围、耗时、结果数量和错误码，不记录财务结果正文。
- 工具输入中的文本筛选不得直接拼接 SQL。
- Secure MCP Tunnel 不可用时不影响桌面应用的本地功能。

## 验证

项目不新增单元测试。实现完成后执行：

```bash
pnpm lint
pnpm build
cargo check --manifest-path src-tauri/Cargo.toml
```

另外手工验证 MCP 初始化、工具发现、锁定状态错误、当前公司默认范围、显式跨公司范围、潜在与已实现双口径、金额恒等关系、明细分页以及 Secure MCP Tunnel 连通性。

## 不在首版范围

- 通过 ChatGPT 写入或删除业务数据。
- 任意 SQL 查询。
- 附件和任务备注全文访问。
- 云端数据库、云同步或电脑离线时访问。
- 公共插件发布和多人 OAuth 授权。
